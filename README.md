# hr-attrition-dashboard
HR Employee Attrition Analysis dashboard built in Google Looker Studio. Identifies key attrition drivers across departments, job roles and overtime patterns.
Google Looker Studio, CSV
Built an interactive dashboard analysing attrition patterns across 1,470 employees. Identified Sales and R&D as highest attrition departments; overtime workers show 3x higher attrition risk. Dashboard accessible via public link.
